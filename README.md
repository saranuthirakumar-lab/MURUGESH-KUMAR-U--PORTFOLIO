## Preview
Open `index.html` in a browser. Keep the folder structure intact so CSS, project pages, and images load correctly.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload all files and folders from this directory.
3. Go to Settings → Pages and publish from the `main` branch, root folder.
4. Open the published URL in a private/incognito window to verify public access.
5. Add actual repository/demo links and any real screenshots before submitting.
